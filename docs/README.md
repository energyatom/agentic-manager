# docs

Product documentation for Agentic Manager lands here as it is built (config schema, crate notes, threat model, the "what this app protects you from" page). The plan lives in `_bmad-output/initiative-agentic-manager/` — start with `initiative-agentic-manager.md` and `reference-workload.md` (the abstract Company A reference company).

- [`config-schema.md`](config-schema.md): what `agentic validate` accepts in a project folder (seats and their capabilities, folders, skills, knowledge and links; Accounts; Sources).
- [`crate-notes/`](crate-notes/): one note per pre-1.0 or pinned crate: the version, where it is used and what not to do with it.
- [`owner-standing-rules.md`](owner-standing-rules.md): what builds decide without asking the owner, and what always stops for the owner.
