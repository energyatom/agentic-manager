- (requirement) R1 (parent R64; arch AD-39, AD-23, AD-35, AD-15): Connector types are listed in one catalogue (Web Search, HTTP Reader, Crawler, API, Feed, Local Repository, Knowledge, Database, MCP, Actions) with their availability; a Source file `sources/<id>.yaml` names its type, owner seat, optional Account, scope, optional trigger, limits, output (a table with mapping and key, records, or knowledge) and, for websites, the date the owner checked the site's terms; a load is a load run without a model whose requests come only from the Source file and in-scope responses; every record carries provenance (Source, connector, URL or file, fetched-at, content hash, load run) and is UntrustedData, rows written by a load carrying taint; no connector, UI string or code path in `crates/` or `web/` names a department source; a Source that adds hosts to its owner seat's allow-list, a new Account or a raised limit is privilege-widening.
- (requirement) R2 (parent R46; arch AD-11, AD-12, AD-10, AD-39; was epic 9 R1, moved 2026-11-18): Built-in web search, read website, arXiv, read file, read URL and search knowledge each declare an action class, network needs and a per-step use count in their manifest, reach a seat only when its seat file grants them, reach the web only through the Web Search and HTTP Reader connectors and `Fetcher` (egress client, robots.txt, per-host pace) to the seat's allow-list, and return UntrustedData that taints the step; in a tainted step read website and read URL fetch only a URL recorded for the step (its trusted inputs, saved links, claimed link lists, source records it read, or search results) used as-is, and web search uses only words from the step's Instruction parts, anything else becoming an Approval with the exact URL or query (parent constraint Untrusted content; arch AD-11); read file and read URL go through WorkspacePath and the capped extract child.
- (requirement) R3 (parent R46; D8; mary D8; was epic 9 R2): A no-key Basic web search works with no signup, is labelled "Basic" wherever search is named, and Doctor flags it as limited with "Add a search key".
- (requirement) R4 (parent R46; D8; prd OQ-4; mary D8; was epic 9 R3): Before the keyed default is fixed, a comparison of Brave, Tavily and Exa against Basic on at least 20 real [removed]-academic queries from the [removed department] work records relevance, coverage of [removed] and South Asian institutions, sign-up friction, free tier, terms and attribution, latency and cost, with a recommended default and a recommendation on whether scheduled runs may fall back to Basic; the owner's choice is recorded.
- (requirement) R5 (parent R46, R70; arch AD-5, AD-17, AD-12, AD-9; ux Voice and Tone; D8; was epic 9 R4): Brave, Tavily and Exa sit behind SearchProvider in the Web Search connector; a provider key is stored only in the keychain; adding a provider adds its egress host through the privilege-widening confirmation ("[removed] may send search queries to api.tavily.com."); keyed queries are service spend priced per call; Settings › Search and the wizard's Accounts screen recommend the chosen default; SearXNG works only as a bring-your-own URL.
- (requirement) R6 (parent R65; parent constraints Robots and terms, Connector caps, Incremental state; arch AD-39, AD-12): The built-in crawler reads static HTML only within its Source's scope (start pages, allowed hosts, include and exclude path globs, depth, page budget), drops query strings unless a glob names them, records out-of-scope links as skipped, keeps its frontier in SQLite so a killed load resumes without refetching committed pages, sends conditional requests and loads only new or changed pages, honours robots.txt (unreachable or 5xx disallows) and Crawl-delay with at least 1 s between requests to one host, and never fetches more pages than its budget.
- (requirement) R7 (parent R65, R70; arch AD-39, AD-17, AD-9): The Firecrawl adapter behind `CrawlService` runs a Crawler Source through the owner's Firecrawl Account (key in the keychain, pinned host): it submits only the Source's scope (start URL, include and exclude paths, depth, page budget, no external links or subdomains, query strings ignored, Markdown of main content), never asks to ignore robots.txt, reserves page budget × credits per page × price before submitting, polls to a final status and reads every result page at once, stores each page as an untrusted record, and settles from the credits Firecrawl reports.
- (requirement) R8 (parent R66; arch AD-39, AD-17): An API Source reads a REST/JSON endpoint with its Account's credentials (header or query key from the keychain), follows cursor, page-number or link-header pagination to its item budget, and maps response fields to table fields by declarative paths with a key, rejecting a row that fails a type with its reason; a Feed Source reads RSS, Atom and JSON Feed and loads only new or changed entries; a sitemap seeds a Crawler Source's frontier within its scope.
- (requirement) R9 (parent R67, R19; parent constraint Incremental state; arch AD-30, AD-39): A Local Repository Source with a table output maps xlsx, csv and json rows to the table by declarative columns, upserts by its key (within a file the last duplicate wins and is counted), rejects rows with reasons, and writes an ingest report (rows read, new, updated, unchanged, duplicates by hash and by key, rejected, files cleaned up); the file is deleted (default), archived or kept only after the load transaction committed, and a failed load leaves it in place with a Failure item.
- (requirement) R10 (parent R68, R62; parent constraints Seat anatomy safety, Files; arch AD-39, AD-30, AD-10; was epic 9 R15 reference-file part): A seat's or team's Knowledge in `.agentic/knowledge/` is indexed for keyword search; `search_knowledge` (read class, local, no network) returns ranked snippets labelled with file and page as UntrustedData that taints the step; `read_file` for a seat resolves only in its knowledge folder, its team's and its claimed drop files; the app never deletes, moves or claims a knowledge file; a team's Knowledge is readable only by that team's seats.
- (requirement) R11 (parent R62; parent constraints Untrusted content, Seat anatomy safety; arch AD-30, AD-11, AD-12; was epic 9 R15 link-list part): A link list in a Local Repository folder (`links.txt`, `.url`, `.webloc`, at most 50 http or https URLs) is claimed once by hash, each URL fetched once through the HTTP Reader within the owner seat's allow-list and robots.txt and stored as an untrusted record whose URL counts as recorded for the steps that read it, while a URL on an unlisted, private, link-local or metadata host is not fetched and is reported for the Agent card's skipped-hosts line.
- (requirement) R12 (parent R61, R62; arch AD-11, AD-12, AD-18, AD-39; was epic 9 R14 and the saved-link part of R15): Read website, read URL, read file, arXiv and search knowledge act as the seat's readers over its saved links, search results and source records; saved links are URLs recorded for each of the seat's steps, fetched only as written on allow-listed hosts; watching pages is a Crawler or HTTP Reader Source that loads only changed pages, or a scheduled step re-reading saved links; no model-invoked tool follows a link found in a page; the API gives the Agent card each seat's Sources with type, output, schedule and health, and the how-to for watching pages ships in `docs/`.
- (requirement) R13 (parent R69, R64; ux EXPERIENCE Connectors surface, Connector catalogue, Source detail, Add Source, Test connector, Ingest report; arch AD-39): The Connectors surface (⌘9) lists Sources with health, last and next load and this week's spend, shows the catalogue by group, and adds a Source in six steps whose Test connector checks credentials, reachability, robots.txt, allow-list and size and shows a one-item sample with its mapping and stated cost while writing nothing; a website Source cannot be saved without the site-terms check; each Source shows its last error, its ingest reports and its load runs; the health of every Source and connector Account is available to Doctor.
- (requirement) R14 (parent R70; parent constraint Connector caps; arch AD-9, AD-11, AD-39): Source limits (items, bytes and spend per load, loads per day, pace per host) are checked before each request and a tool's per-step use count before each call; paid connector use is service spend priced from the dated services section of the price file, reserved before the call against the Source or step, seat, workflow and company scopes, settled from reported usage, shown on the meter and in Models & Costs, and a reservation that would cross a cap makes no call and raises a Budget ask.
- (requirement) R15 (parent R71; parent constraint Incremental state; arch AD-8, AD-39): Every Source keeps item keys, content hashes, ETags, frontier and cursors; a load over unchanged input writes nothing; each consuming step reads only records new or changed since its last successful run through a cursor that advances in the step's commit; an interrupted load resumes without repeating committed work.
- (requirement) R16 (parent constraints Untrusted content, Generic engine, AI ship and rollback; parent R26): The injection pack gains connector cases (a poisoned crawled page, feed item, API field, spreadsheet cell, link-list page, knowledge file and saved-link page) that yield zero outbound calls, zero approvable proposals and zero requests carrying a canary on the fake provider and one real local model; [removed department]'s Sources ship as Source files under `templates/` and load green end to end, with the denylist scan clean.
