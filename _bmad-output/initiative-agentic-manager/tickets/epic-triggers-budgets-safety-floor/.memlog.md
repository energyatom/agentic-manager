- (requirement) R1 (parent R17; arch AD-18, AD-19; ux Schedule picker): A workflow's trigger fires from our own scheduler loop over croner and jiff through the Clock port, ticking at most every 30 s, with each trigger's next fire, last fired and state (active, or paused with reason stop, budget, owner or invalid-config) persisted; scheduled runs record origin scheduled; a fire while the workflow has an active run is skipped and logged; the core reads every trigger back in words ("Every Tuesday at 08:00 IST · if the Mac was asleep, run once on wake") for the CLI and the API.
- (requirement) R2 (parent R17; arch AD-18): A wall-clock jump across fire times (sleep and wake) is detected and missed fires follow the trigger's catch-up policy from persisted state: once (default) starts exactly one run, skip starts none and logs the missed fires, all queues one run per missed fire in order; catch-up runs record origin catch-up; a paused trigger never catches up; DST follows croner's documented semantics.
- (requirement) R3 (parent R18; arch AD-15, AD-19): A Human starts any workflow from `agentic run` or the API's run-start command; the run records origin manual, uses the manual caps and queues behind an active run of the same workflow.
- (requirement) R4 (parent R20; parent constraint Spend caps; prd RULE-11; arch AD-9; D2): Before every model call the reservation is checked atomically against every enclosing scope (call, step, run, seat per run, week and month, workflow per run, week and month, company week), with scheduled runs held to their own lower caps; if any scope would exceed, no call is made, the step waits with a Budget ask naming the scope, spend and cap, and every schedule of the affected scope pauses with reason budget; an informational Budget item is raised once per scope and period at 80%; settled plus reserved spend against each cap is readable from `agentic status` and the API. Threshold: settled spend never exceeds a cap.

- (requirement) R8 (parent constraint Files; prd RULE-14; arch AD-30): Every file path taken by tools, parsers and imports is a WorkspacePath that is canonicalised and rejects escapes, symlinks included; parsers run in the `agentic __extract` child with size, page, archive-expansion and time caps, and a refused or crashing parse ends in a worded error while the engine keeps running; fuzz targets for PDF, xlsx, docx and zip run nightly.
