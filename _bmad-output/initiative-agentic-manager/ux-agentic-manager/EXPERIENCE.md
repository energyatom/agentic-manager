# Agentic Manager — Experience Spine

## Foundation

**Form factor.** A single-user, desktop-class window. Browser mode (current Chrome, Safari, Firefox and Edge on `127.0.0.1`) ships first; the Tauri desktop shell wraps the same web UI later. v1 is macOS on Apple Silicon only, the desktop app and browser mode on the Mac (amended 2026-11-19, owner Mac first); Windows 11 and Linux x64 follow in v1.x. There is no mobile surface (PRD non-goal). The designed size is 1440×900; the minimum window is 1024×700.

**UI system.** React + TypeScript on accessible headless primitives (Radix-style: dialog, popover, menu, tabs, toast). `DESIGN.md` owns every visual token; this spine specifies behaviour only. Light and dark follow the OS setting, with an override in Settings.

**Posture.** The org chart is home. Everything else is reached from a seat, team or run, or through the sidebar, ⌘K and ⌘J. Defaults come first and advanced options sit behind **More**. Nothing runs, changes config, widens a privilege or sends without an owner action (RULE-3).

**Visual references.** Key-screen mocks live in [`mockups/`](mockups/) and are linked inline below. The owner's previous tool is in [`imports/crewai-studio-canvas-current.png`](imports/crewai-studio-canvas-current.png) as the anti-reference. Where a mock and this spine disagree, the spine wins.

**Sidebar:** Org, Inbox (count), Runs, Workflows, Tables, Connectors, Dashboards, Models & Costs, Settings; then a **Teams** list (status dot + weekly cost); then the Doctor status line at the foot.

**Toolbar (every surface):** company name · **Cost meter** · breadcrumb · Search ⌘K · Assistant ⌘J · **Stop everything**.

**Stacking.** At most one side sheet or slide-over, plus one popover or confirmation on top. Opening a second sheet replaces the first; the first is reachable with ⌘[ (back). The Assistant and a seat sheet never show together: ⌘J closes the sheet and keeps its edits.

## Voice and Tone

Microcopy. Brand posture lives in `DESIGN.md` › Brand & Style. Plain words, sentence case, short complete sentences, no exclamation marks, no emoji. Name the seat, say the number, and give the next action.

| Do | Don't |
|---|---|
| "Nothing needs you." | "You're all caught up! 🎉" |
| "About ₹80–120 · based on your last 4 runs" | "Estimated cost: ₹97.43" |
| "About ₹70–150 · rough, no history" | "Estimate unavailable" |
| "D1-E1 is searching the web…" | "Agent 3 executing tool_call" |
| "May struggle with tool calls — D1-E2 uses Web search and Read website." | "Incompatible model" (and a disabled row) |
| "Stopped at budget · D1-E3 spent ₹90 of ₹90 this week. Schedules paused." | "Error: budget exceeded" |
| "Search was blocked. Fell back to Claude Haiku; still blocked. Nothing was spent beyond ₹4." | "Step failed (code 502)" |
| "Approve 41, return 1" | "Submit" |
| "Waiting for 2 of 3 · timeout in 1h 52m" | "Pending (1/3)" |
| "Hands across to Department 1 · Document A v7 · within grant, read-only" | "Cross-tenant payload transfer" |
| "D1-E1 may send search queries to api.tavily.com." | "Grant network permission?" |
| "Local search (SearXNG) · free, no key" | "Basic search (limited)" |
| "Local search sends each query to: Engine 1, Engine 2, Wikipedia. They see the query and this computer's IP address, never your files or tables." | (silence about who sees a search) |
| "Yes, allow api.tavily.com" / "Keep current access" | "OK" / "Cancel" |
| "Changed D1-E2's fallback model. Undo" | "Settings saved successfully" |
| "Untrusted · from web page site-b.example/page-1" | "External content" |
| "Drafts only. Agentic Manager never sends email." | (silence about what the app will not do) |

**No department vocabulary in product strings** (RULE-2). Names of seats, departments, tables, documents and Sources come from the owner or the clearly labelled sample company (Company A: Owner, Department 1 with D1-Head and D1-E1 to D1-E3, Department 2 with D2-Head and D2-E1 to D2-E4, Document A, Table T1, Report R1, Skill S1); product chrome says seat, team, department, workflow, run, table, document, hand-off, branch, lineage, Inbox.

**Hats** are written as "You (Reviewer)", "You (Developer hat)" in history and provenance.

**Currency.** The company currency is pre-filled from the Mac's locale and confirmed in the wizard; amounts use its symbol and the locale's digit grouping (for example "₹1,20,000" for INR, "€120.000" for EUR); USD on toggle. Local calls show zero in the company currency, for example "₹0 · 41k tokens · 2m 40s" for a company in INR. Company A's own figures stay in INR.

## Component Patterns

Behavioural. Visual specs live in `DESIGN.md` › Components under the same names.

| Component | Use | Behavioural rules |

| Cost meter | Toolbar, all surfaces | Visual: `{components.cost-meter}`. Shows weekly company spend against budget. Click opens Models & Costs › This week. At 100% it shows "Stopped at budget", every run that would spend is paused, and a Budget ask lands in the Inbox; clicking the meter then opens that Inbox item. On Windows and Linux (v1.x), ⌘ maps to Ctrl. Single-key shortcuts (N, A, S, E, R, F, L, ?, Space) act only when focus is on the surface they belong to (never inside a text field), and Settings › General can turn them off (WCAG 2.1.4).

**Pointer.** Click selects; double-click or Return opens. Drag: seats (re-parent), tools onto a seat, steps (reorder), dashboard cards. Hover reveals grant lines, hand-off lines and seat tooltips; nothing actionable is hover-only (selection, Team sheet › Hand-offs and Team sheet › Grants give the same facts).

**Motion.** Durations run from `{motion.quick}` to `{motion.sheet}` with `{motion.easing}`, used only to show cause: sheets slide from the right edge; a new Inbox item fades in at the top of the list; the running dot (`{components.status-dot.running}`) pulses at `{motion.pulse}`; a team expands from its box. The meter updates digits at most once per second. **Reduce Motion:** slides become cross-fades of 0–100 ms, the pulse becomes a static dot, and expand/collapse is instant.

**Saving.** Fields save on blur or Return; there is no Save button outside dialogs. Every save is reversible through Undo and History.

**Banned:** blocking modals for estimates; any global auto-approve or "always allow"; auto-running anything after import or Assistant output; hover-only actions; infinite scroll in the Inbox (it paginates by week); toast-only errors (every error also lives on its surface); confetti, streaks or celebratory animation; rendering model output as raw HTML.

## Accessibility Floor

Behavioural. Visual contrast lives in `DESIGN.md` › Colors (all text pairs ≥ 4.5:1, controls ≥ 3:1).

- WCAG 2.2 AA in both themes.
- **Screen reader.** The org chart is exposed as an ARIA tree (`role="tree"`; teams and seats are `treeitem` with expanded state). A seat is announced as "D1-E2, Department 1, gpt-oss-20b on this Mac, running, ₹0 this week". Human seats are announced with "you, CEO". Grant and hand-off lines are announced in the Team sheet's Grants and Hand-offs lists, not on the canvas. Parallel branches are a group ("Step 2, 3 branches in parallel, 1 of 3 done"); the lineage is a nested list.
- **Live regions.** The cost meter is `aria-live="off"` while ticking and announces only threshold changes (80%, stopped). Run step changes are announced politely ("Step 3 done"). New Inbox items are announced politely with the count.
- **Focus.** A visible 2px focus ring in `{colors.accent}` on every control. Opening a sheet moves focus to its heading; Esc returns focus to the invoking element. The palette and the Assistant trap focus while open.
- **Untrusted wells** carry a label read before their content ("Untrusted content from site-b.example"). Colour is never the only signal: every status has a word.
- **Targets** are at least `{spacing.hit-target-min}` square (2.2 target size); controls are `{spacing.control-height}` tall by default.
- **Reduced motion** as above. **Increased contrast** (OS setting) raises hairlines to `control` and removes the hatch.
- **Text scaling:** the layout holds at 200% browser zoom with no horizontal scroll at 1280 px; sheets become full-width below 1024 px of viewport.
- Strings are externalised; dates, times and currency are locale- and timezone-aware.

## Inspiration & Anti-patterns

- **Lifted from Things:** density and calm, instant reversible edits with undo, one sentence per empty state.
- **Lifted from Linear:** ⌘K as the command centre, keyboard-first navigation, status vocabulary as small pills.
- **Lifted from n8n credentials:** Accounts as named, reusable, test-on-save connections picked from one menu, fixed by adding capability chips and Test this model.
- **Lifted from Paperclip:** the company/org-chart mental model, heads of departments reporting up to the owner.
- **Lifted from CrewAI flows and hierarchical crews:** parallel tasks that a manager agent consolidates, and flows that start other flows; shown here as branch groups in the step list and a one-line "Starts when…", never as a canvas.
- **Lifted from CrewAI Studio:** per-seat model choice and drag-and-drop tools onto a seat.
- **Rejected: the CrewAI canvas layout** (`imports/crewai-studio-canvas-current.png`). Agents in a top row and tasks in a bottom row joined by curves force the eye to zig-zag; instruction text truncates; "No triggers configured" sits off to the side. Replaced by a top-down org tree (who) and a separate vertical step list with named seats and written hand-offs (what, in order), with the schedule stated in words at the top of the workflow.
- **Rejected: node-graph builders** (Langflow, Flowise style). The company is the interface.
- **Rejected: estimate modals and single-number estimates.** False precision erodes trust.
- **Rejected: global auto-approve or "always allow"** (RULE-3). This supersedes the per-action "always allow" idea in Sally's round-1 position.
- **Rejected: local models as an "advanced" path.** Same card, same menu; only the badge differs.
- **Rejected: a paid key as the only way to search** (the owner's CrewAI experience of being asked for a search API key). Every capability ships built in and free; keys are optional upgrades (RULE-20, 2026-11-18).
- **Rejected: fake "ready" template cards** for Software, Optics and Mechanical departments (D7). They are absent until tested.

## Key Flows

Journeys use the abstract sample company (Company A: the Owner, Department 1 and Department 2; D1-E2 is the seat on a local model). They mirror the PRD journeys UJ-1 to UJ-3 (amended 2026-11-18, reconcile); the PRD wins on substance.

### UJ-1. The Owner gets Report R1 and checks how it was made.

Tuesday 08:45. Overnight Flow F1 ran: D2-Head produced Document A from D2-E1 to D2-E4's rows in Table T1; it crossed into Department 1, where D1-E1, D1-E2 (on this Mac) and D1-E3 worked on it in parallel; D1-Head consolidated the three and handed the result back; D2-Head wrote Report R1, and D1-Head approved it as the review gate from the other department.

## Open Questions

- **Accent hue.** A native blue is assumed; the owner may pick another single accent. This changes only the `accent*` tokens.
- **Product name (OQ-1).** Strings use "Agentic Manager"; the wizard, About page and server-unreachable state carry the name.
- **Default caps (OQ-8).** Placeholders until the owner decides: ₹150 per scheduled run, ₹250 per manual run, ₹600 per week for the workflow and the company (initiative assumption, restated 2026-11-18); seat-level figures in the mocks are illustrative owner-set seat caps. The UI reads all of them from config.
- **Keyed search upgrade (OQ-4, restated 2026-11-18).** Local search is the default; Settings › Search names a Recommended optional upgrade only if the comparison and the owner choose one.
