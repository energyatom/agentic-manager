# Agentic Manager

## Description

An open-source (MIT), local-first app for running an AI company from an org chart: the owner builds departments of AI seats that hand work to each other, fan it out in parallel and review each other, takes seats in it as CEO, Vision Creator, Reviewer or Developer, gives every seat its own model and budget, and lets it run on a schedule, with results in built-in tables and documents. It sets up like CrewAI Studio, runs like Paperclip and feels as calm as an Apple app, from one signed install with no Docker or cloud account and safety a stranger can verify. It is open by default: web search, reading and crawling pages, and folder access with knowledge (restated 2026-11-19: a seat links folders and its model reads the files) are built into the install and work with no account or key, each switched on per agent, so the only limit is the owner's compute; outside providers are optional upgrades (owner, 2026-11-18). v1.0 is done when the owner's own company departments, with at least one cross-department flow, have run on it for four clean weeks and the trust gate is green; every test and sample uses the abstract Company A (reference-workload companion). Distilled from the final PRD, architecture and UX spines under the binding party record and the owner's reference-company direction of 2026-11-18.

## Outcome

the owner, a time-poor owner-operator, gets advice from the owner's AI departments that is strong and traceable — who contributed what, from which inputs, with which model and at what cost — and acts on it instead of maintaining tools or guessing model costs; measured as at least 3 advice actions a week with review held to 15 minutes or less (prd SM-1).

- R77 (prd FR-60; owner REPLAN 2026-11-18; arch AD-44, AD-18): An event — a document updated, a step completed or a workflow completed — starts a workflow in any department; `agentic validate` rejects a trigger cycle, and at run time a start past the maximum chain depth (default 3, at most 5) or into a workflow already in the chain is refused with a Failure Inbox item and an audit entry.
- R78 (prd RULE-20 Open by default; owner, 2026-11-18: "Agentic Manager must have all the open options; the only limit should be compute"): Every capability works out of the box with free, local, key-free components; paid or keyed services are optional upgrades added through Accounts, never required and never pre-selected silently; a fresh install with only a local model server and no keys completes the golden Company A F1 run, its web search step included.
